A repository of QuizXpress samples

- [script](script): example quizzes with slide scripts (JavaScript), each with its script and an
  explanation.
- [skills](skills): skills for AI assistants such as Claude that work on quizzes through the
  QuizXpress MCP.
  - [quizxpress-scripting](skills/quizxpress-scripting): writing, adding and debugging slide
    scripts. Copy the folder to `~/.claude/skills/` for Claude Code, or zip it and upload it under
    Settings > Capabilities > Skills in Claude.
